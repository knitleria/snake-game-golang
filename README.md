# Как скачать и запустить Snake Game

Игра собирается автоматически для трёх операционных систем и публикуется в разделе
[**Releases**](https://github.com/knitleria/snake-game-golang/releases) на GitHub.
Каждому игроку нужно скачать **только один** архив — тот, что подходит его системе.

## 1. Скачивание архива под свою ОС

Откройте [страницу последнего релиза](https://github.com/knitleria/snake-game-golang/releases/latest),
разверните раздел **Assets** и скачайте нужный файл:

| Операционная система | Файл для скачивания            | Что внутри  |
| -------------------- | ------------------------------ | ----------- |
| Windows              | `snake-windows-amd64.zip`      | `snake.exe` |
| macOS                | `snake-macos-amd64.tar.gz`     | `snake`     |
| Linux                | `snake-linux-amd64.tar.gz`     | `snake`     |

> Все сборки 64-битные (`amd64`). На Apple Silicon (M1/M2/M3) игра запускается
> через Rosetta 2 — см. раздел про macOS ниже.

---

## 2. Windows

1. Распакуйте `snake-windows-amd64.zip` (правый клик → «Извлечь всё»).
2. Запустите `snake.exe` двойным кликом.
3. При первом запуске Windows может показать окно **«Защита Windows SmartScreen»**.
   Нажмите **«Подробнее» → «Выполнить в любом случае»**.

---

## 3. Linux

```bash
tar -xzf snake-linux-amd64.tar.gz
chmod +x snake
./snake
```

Для запуска нужны системные графические и аудио библиотеки. На Debian/Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y libgl1 libasound2 libxi6 libxxf86vm1
```

---

## 4. macOS (подробно)

Приложение **не подписано** сертификатом разработчика Apple и не проходило
нотаризацию, поэтому встроенная защита **Gatekeeper** по умолчанию его блокирует.
Это нормально — нужно один раз вручную разрешить запуск. Ниже два способа.

### Шаг 1. Распаковать архив

Дважды кликните по `snake-macos-amd64.tar.gz` в Finder или выполните в терминале:

```bash
cd ~/Downloads          # или туда, куда скачали файл
tar -xzf snake-macos-amd64.tar.gz
```

Появится исполняемый файл `snake`.

### Шаг 2. (только Apple Silicon — M1/M2/M3) установить Rosetta 2

Сборка под macOS — 64-битная Intel (`amd64`). На чипах Apple она работает через
Rosetta 2. Если Rosetta ещё не установлена, выполните:

```bash
softwareupdate --install-rosetta --agree-to-license
```

> Узнать свой процессор: меню Apple () → «Об этом Mac». «Apple M…» — это
> Apple Silicon, «Intel» — Rosetta не нужна.

### Шаг 3. Снять «карантин» и разрешить запуск

При скачивании из интернета macOS вешает на файл атрибут карантина. Из-за этого
при двойном клике появляется ошибка вроде:

> «Невозможно открыть программу «snake», так как Apple не может проверить её на
> наличие вредоносного ПО»

или

> «Программа «snake» повреждена и не может быть открыта».

**Самый надёжный способ — через терминал.** Перейдите в папку с файлом и выполните:

```bash
chmod +x snake                       # сделать файл исполняемым
xattr -d com.apple.quarantine snake  # снять атрибут карантина
./snake                              # запустить
```

Если команда `xattr` сообщает, что атрибута нет — ничего страшного, просто
запускайте `./snake`.

**Альтернатива через интерфейс (без терминала):**

1. В Finder кликните по файлу `snake` **правой кнопкой** (или Ctrl+клик) → **«Открыть»**.
2. В появившемся окне ещё раз нажмите **«Открыть»**.
3. Если кнопки «Открыть» нет, откройте **Системные настройки → Конфиденциальность
   и безопасность**, пролистайте вниз до сообщения о заблокированном «snake»
   и нажмите **«Подтвердить запуск» / «Open Anyway»**, затем повторите запуск.

После первого успешного запуска система запомнит разрешение, и дальше игра будет
открываться обычным двойным кликом.

---

## Возможные проблемы

| Симптом                                            | Решение                                                                 |
| -------------------------------------------------- | ----------------------------------------------------------------------- |
| macOS: «программа повреждена»                       | Снимите карантин: `xattr -cr snake` (или `xattr -d com.apple.quarantine snake`). |
| macOS: ничего не происходит на Apple Silicon        | Установите Rosetta 2 (см. Шаг 2).                                       |
| Linux: ошибка о нехватке библиотек (`libGL`, `libasound`) | Установите зависимости из раздела Linux.                          |
| Любая ОС: «нет прав на запуск»                      | Сделайте файл исполняемым: `chmod +x snake`.                            |
